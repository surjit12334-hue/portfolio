# Surjeet Singh - Portfolio

A personal portfolio website built with plain HTML and CSS.

## 🚀 Features

- Responsive design that adapts to mobile and desktop screens
- Modern dark gradient theme with glassmorphism effects
- Hover animations on project cards and profile image
- About section, project showcase, and contact footer

## 📁 Project Structure

```
├── index.html   # Main portfolio page
├── CSS1.css     # Styling and layout
└── logo.jpeg    # Profile picture
```

## 🛠️ Built With

- HTML5
- CSS3 (flexbox, grid, animations)
- Placeholder images from [picsum.photos](https://picsum.photos)

## 🚀 Getting Started

Simply open `index.html` in any web browser:

```bash
open index.html
```

No build tools or dependencies required.
